🌧️ Project VARSHAA

AI-Driven GIS Platform for Cloud Seeding & Crop Protection

Team: The Axiom | Problem Statement: SIH26076

🌍 Overview

Vulnerable agricultural regions across India face extreme weather crises with no integrated infrastructure for real-time mitigation. VARSHAA is a civic-tech Web GIS platform designed to revolutionize disaster response.

By fusing live satellite data, atmospheric monitoring, and Machine Learning, VARSHAA acts as an intelligence and decision-support system to automate cloud seeding feasibility checks, mitigating severe droughts and washing down urban air pollution.

✨ Key Features

🗺️ Live Weather & Risk Map: Interactive GIS dashboard (via Leaflet.js) visualizing real-time drought risks, AQI, humidity, and rainfall deficits.

🧠 Smart AI Feasibility Check: Machine learning algorithms evaluate live atmospheric data (moisture, cloud thickness, temperature) to determine if cloud seeding operations are Optimal, Marginal, or Unfavorable.

📡 Direct Warning System: Automated alert dispatch capabilities to notify local authorities and Krishi Vigyan Kendras (KVKs) for farmer advisory routing.

🎙️ Voice-Activated Intelligence: Integrated browser-based voice recognition to quickly query rainfall stats and seeding statuses hands-free.

🛠️ Tech Stack

• Frontend: HTML5, Tailwind CSS, Vanilla JavaScript, Leaflet.js (Web GIS)

• AI & Data Processing: Python, Scikit-learn

• APIs & Integrations: Open-Meteo API (Live Meteorological Data), Web Speech API

• Database (Planned): PostgreSQL with PostGIS / GeoJSON
